# Cinematic storefront QA

## Reference translation

The interaction reference was used for pacing and spatial storytelling only: a long pinned chapter, restrained camera-like scale changes, large editorial type, high-contrast scene transitions, persistent progress/escape controls, and a decisive final CTA. No reference-site code, copy, artwork or proprietary assets were used.

The implementation uses Rehmat Panjab's existing campaign photography, bottle imagery, forest/ivory/amber palette, display typography, oil ripple language and Rehmat Guide entry point.
